# Synthesize

帮助读者理解这些材料对问题带来了什么改变、这个判断为什么成立、什么可以复用。选择与推理在正文中完成，不让读者从零散笔记或链接中自行拼凑。

## 选择值得回答的问题

从请求推断读者和用途；只有缺失的区分会实质改变内容时才提问。一段零散想法和一组 Run 同样可以作为输入。识别问题、此前的认识或备选方案，以及当前真正重要的不确定性。按对理解或决定的影响选择内容，而不是按投入的工作量或时间顺序。省略负结果、矛盾或限制会改变含义时，必须保留。

按用途调整重点：

- 梳理想法：连接目标、假设、张力和选项；区分有用的方向与未经检验的解释。
- 实验总结：做了什么比较、比较是否有效、在多大程度上支持或挑战结论。
- 研究笔记：认识的变化、可能的机制、反例，以及可能帮助相关问题的方法。
- 周报：与目标相关的进展、发现和决定，以及后续工作。

同一证据面对不同读者时保持相同的事实含义。

## 连接证据与判断

先读来源再解释。识别哪些观察相互支持、回答问题的不同部分、相互冲突或无法比较，并核对决定这一点的条件：评价口径、数据、基线、运行假设。不平均不可比的结果，也不只挑有利结果。

材料支持时，说明认识发生的变化：学到了什么、哪种解释变得更可信或更不可信、排除了哪个选项、还剩什么未决。如果笔记只显示完成了工作或不确定性没有变化，就如实说明，不制造发现。把来源作者的结论当作需要对照证据检验的主张。结果不一致且没有确定原因时，保留分歧并指出什么能区分各种解释。证据不足以证明收益，不等于方法永远无效。

## 提炼可迁移的经验

只有会改变他人在类似情境中做法的经验才保留。区分个案条件与得出判断的推理，用材料中的反例或条件变化检验它，并写明适用情境、建议的做法、以及什么情况需要调整。经验的强度与证据相称：一次观察只支持局部提醒或假设，不支持规则。把“加强实验规范”这类空泛建议换成它应当改变的具体决定。

## 交付

先写主要认识，再给出评估它所需的事实和理由；关键数值、单位和条件写进正文，来源链接用于追溯。后文建立在已说明的证据上，不在发现、下一步和经验中重复同一结论。交付可直接使用的文字；总结引用已有 Run，不创建 Run。起草的飞书周报是可粘贴的文字；发送是另一项需要明确授权的操作。
