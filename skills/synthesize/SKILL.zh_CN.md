# Synthesize

帮助读者理解材料怎样改变了对问题的认识、判断为何成立，以及哪些经验可以复用。在正文中完成必要的筛选和推导，让读者不必从零散笔记或来源链接中重新拼接理由。

## 选择值得回答的问题

从请求和上下文判断读者与用途，只有缺失的区别会实质改变内容时才询问。一段零散思路或多份材料都可以作为输入，不要求已有项目、Spec 或 Run。

从用户提供或当前任务相关的材料出发，辨认问题、已知的原有理解或备选方向，以及当前重要的不确定性。按内容对理解、决定或后续工作的影响取舍。工作量和时间顺序本身不决定重要性；删去负结果、矛盾或限制会改变含义时，必须保留。

根据用途选择重点：

- 整理思路时，连接目标、假设、主要矛盾和选项，区分有价值的方向与尚未验证的解释。
- 总结实验时，说明做了什么比较、比较是否成立，以及结果能在多大范围内支持或挑战研究判断。
- 写研究笔记时，保留认识变化、可能的机制、反例，以及有助于处理相关问题的方法。
- 写周报时，将有意义的进展、发现和决定联系到目标与后续安排；方法只展开到读者理解这些进展所需的程度。

这些是内容选择，不是必需章节。同一证据面向不同读者时，事实含义必须保持一致。

## 建立证据与判断之间的关系

先阅读源材料，再解释它。辨认哪些观察相互支持，哪些回答不同部分，哪些冲突，哪些尚不可比较。核对决定这些关系的条件，例如评价口径、数据、基线或生效假设。不合并不可比结果，也不只选最有利的证据。

材料支持认识变化时，说明学到了什么、哪些解释变得更可信或更不可信、排除了哪个选项，以及什么仍未解决。笔记只记录完成工作或未改变的不确定性时，如实交代进度，不制造发现。

区分观察、解释和拟采取的行动。来源作者的结论也需要对照其证据判断。结果不同时，有已知原因就解释原因；尚无定论就保留分歧，并指出什么信息能够区分可能的解释。不为让总结显得完整而编造因果故事。

明确证据与选择之间的联系：证据为何影响当前决定，未决问题如何导出建议的下一步。将已记录的决定与自己的建议分开。证据不足以支持收益，不代表某种方法永远无效。

## 提炼能够迁移的方法

寻找可以改善后续任务的判断办法，例如怎样识别有效对照、找出会改变选择的不确定性、区分竞争解释，或决定何时停止投入。某条经验能改变读者处理同类问题的做法时，才值得保留。

区分案例特有的条件与产生有效判断的思考办法。目标、数据或资源限制改变后，哪些理由仍然成立，哪些必须重做？用材料中的反例或条件变化检验候选经验；缺乏依据的延伸明确写成待检验建议。

交代适用情境、关键行动或判断、为何有效，以及出现什么证据或条件时需要调整，让经验可以使用。抽象到能够迁移的程度，同时保留判断成立范围所需的条件。用它具体改变的决定，替代“加强实验规范”之类宽泛建议。

经验的强度应与材料相称。一次观察可能只支持局部提醒或待验证解释；可迁移规则需要说明机制与条件为何能延伸到该案例之外。不要求每篇产物都有新洞察、普遍方法或“方法论”章节。方法首先应该改善综合工作本身。

例如，一个示意案例中，旧基线与候选使用了不同评价脚本，早期分数不能证明可比的收益；统一脚本后的比较仍无定论时，应解释这一限制。可保留的有条件经验是：复用历史基线前，核对评价口径和运行条件，必要时做小规模校准比较。它帮助提高比较的可信度，不能证明候选在其他条件下无效。正式报告必须使用实际结果和来源。

## 写出读者能够跟随的结论

先给核心认识，再提供判断它所需的事实和理由。关键证据写进正文，准确来源链接负责追查，不能代替结果解释。数值、单位、技术标识、条件和不确定性会改变结论时，应保留。

使用适合目标读者的自然语言、稳定术语、具体主语和动词，以及相连的句子；在上下文中解释陌生概念。删除重复过程和“深入分析”“将优化”等空话，保留具体改法、理由和必要的后续步骤。句子虽短但省略了证据与结论的联系，仍会增加阅读成本。

推导用段落，比较用表格，文字难以解释的关系可以用图。只有调整输入有助理解时才制作交互解释。示意和模拟数据明确标注，不能代替实测证据。篇幅和结构由信息需要决定。

交付前判断：读者能否从正文理解结论及关键理由，留下的经验能否在所述条件下指导后续选择。每段应增加必要的事实、关系或影响；已有解释的证据直接承接，不在发现、下一步和经验中反复重述同一结论。经验只保留会改变后续选择的部分，合并重叠判断，删去只把本次结果换个说法的条目。删掉证据不支持的拔高，补回会改变判断的遗漏条件。

## 保持源事实不变

交付可直接使用的正文，不只说准备总结或提供写作计划。用户要求保存或原任务已经包含保存时，沿用指定或已有的笔记、周报位置。保留并引用原始 Run 事实，汇总文字本身不新建 Run。产生新证据的计算属于另一项工作，遵守各自的授权和证据要求。

主 Agent 在原授权内，把已采用的项目决定整合回相关 Spec。笔记和周报引用该决定，不静默成为竞争的设计归属。准备飞书周报时交付可直接粘贴的正文，实际发送需要明确授权的目的地和动作。
