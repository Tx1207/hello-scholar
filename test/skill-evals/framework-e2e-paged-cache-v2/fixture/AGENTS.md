# Paged Cache Project Rules

- Read the Accepted Spec and current code before proposing changes.
- Keep the public `CacheAllocator` import and method behavior stable.
- Put tests under `tests/`, benchmarks under `scripts/`, and formal run evidence under root `runs/`.
- A Plan, Tasks, implementation, and Architecture update each require their own stated gate.
- Run commands from the project root and report exact output and exit status.
