# Batch Reporting Pipeline Rules

- The current Spec Bundle defines product requirements and document lifecycle state.
- Formal benchmark work is recorded at `runs/<run-id>/record.md`; project records carry the required provenance for that work.
- Do not change source, tests, lifecycle documents, generated Indexes, or Run material without explicit user authorization for the relevant work.
- Run Python checks and the absolute hello-scholar CLI from the project root. Generate Indexes only during authorized documentation maintenance.
