# Cache Benchmark Project Rules

- Repository documentation and Run Records are written in English; commands, paths and identifiers remain exact.
- `SPEC-021` and its Approved Plan are the authoritative acceptance, provenance and ordering contract for this formal retained benchmark.
- Use the committed configuration and request trace exactly once. Do not tune the cache, rerun, or alter inputs after seeing a result.
- Run Python prechecks and verification with `-B`; generated bytecode is not project evidence.
- Preserve process-start evidence under `outputs/`, metrics under `results/`, concise runtime text under `logs/`, and declare the `checkpoints/` location even though this benchmark emits no checkpoint.
- Generate Indexes only with the absolute hello-scholar CLI. Never create `run.json` or a second Run summary.
