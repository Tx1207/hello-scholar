# Retrieval API Rules

- Read public route code, caller behavior, interface tests, Architecture, and Specs before proposing an API design.
- Ask one question at a time. No source or formal document writes before the matching approval gate.
- A batch route needs an independent lifecycle and explicit creation approval; new Specs remain draft until separately accepted.
- This run ends at a planning handoff. Do not create Plan, Tasks, or implementation.
- Generated Indexes are CLI-owned. Do not launch visual companion processes or write memory paths.
