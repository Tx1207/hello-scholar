# Quantization Lab Rules

- Project documentation and Run Records are written in English.
- Existing terminal evidence is immutable. Never rerun a quantization command during Record closeout and never edit `logs/` or `results/`.
- Derive each terminal classification from the saved exit status, result validity and hypothesis evidence; do not infer it from a Run name.
- Existing Records require the user's requested review gate before any closeout write.
- Keep full logs and structured metrics in their artifact directories. Quote only concise evidence in `record.md`; do not create a report, summary, replacement Run or `run.json`.
