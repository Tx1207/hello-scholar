# Prompt Routing Sandbox Rules

- Project documentation and Run Records are written in English.
- This repository is a disposable linked worktree with synthetic cases, no credentials, no network, no public API and no persisted customer format.
- One prompt sweep is capped at six cases and three thresholds, runs for seconds with built-in Node.js only, and cannot be merged or shipped directly.
- Sweep output is transient evidence, not a durable design decision or production configuration; any later dependent work must retain traceable provenance.
- Do not create a Worktree from inside this one. Do not change source or cases after seeing results, and never create `run.json` or a second Run summary.
