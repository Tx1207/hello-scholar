# Exploration Boundary

The sweep operates only on `cases/prompt-cases.json` and calls no service. It is disposable, reversible and bounded to one local process over 18 score comparisons. The output is evidence for a possible future routing Spec, not a production configuration or implementation.

The supplied repository is a linked disposable Git worktree. Production data, a shared deployment path, a public API or persisted-format change, an irreversible operation, unbounded cost, or direct production use would materially change the risk and cost facts and must be surfaced before launch.
