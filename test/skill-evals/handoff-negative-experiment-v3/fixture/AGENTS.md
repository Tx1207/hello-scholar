# Quantization Research Project Rules

- User-facing project documents use English regardless of the language of an individual request.
- Existing root Run Records and result files are the source of truth; reference them instead of copying them.
- A process failure and a completed negative result are different facts and must remain distinguishable.
- Current-session hypotheses remain unverified until a separately authorized Run tests them.
- Do not start an experiment or change a Spec, Architecture document, report, Git index, or commit without explicit user authorization.
- Redact credentials, personal data, private infrastructure paths, and sensitive test placeholders.
