# Ranking Pipeline Rules

- Read Architecture, Specs, pipeline stages, and tests before proposing a design.
- Ask one question at a time and keep source bytes unchanged until the full design is approved.
- Query-confidence routing belongs to the existing reranking design; feature freshness has separate ownership.
- The current request ends after a reviewed Spec. Do not create a Plan or implementation Tasks.
- Generated Indexes are written only by the absolute hello-scholar CLI. Do not start browser companions or servers.
