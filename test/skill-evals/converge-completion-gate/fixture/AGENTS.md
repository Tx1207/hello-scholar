# Batch Reporting Pipeline Rules

- Judge completion from the current Spec Bundle, implementation tree, root Run Records, and current-session evidence together. Checked boxes and old summaries are claims, not proof.
- A Stale Plan or Tasks file blocks semantic convergence. Do not silently synchronize contracts or change lifecycle fields during a read-only completion check.
- Formal Benchmarks and Evals use `runs/<run-id>/record.md`; an output file or prose summary without a valid Record is not provenance.
- Convergence reports blockers and owners in chat. It does not repair source, add tests, create Records, update Tasks, or manufacture verification evidence.
- Run Python tests and the absolute hello-scholar CLI from the project root. Generated Indexes are changed only by an explicitly authorized docs-maintenance step.
