# Batch Query Service Rules

- Preserve the existing single-query API unless an approved API contract changes it.
- A public endpoint or module-ownership change requires a reviewed API design before implementation.
- Identify unresolved constraints and compare viable API contracts before selecting one.
- Current architecture notes describe behavior; they do not authorize a future API design.
- Use only Node.js built-ins and run `node --test` from the project root.
