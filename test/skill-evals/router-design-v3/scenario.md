# Public Batch Query API

## 项目背景

这是一个无第三方依赖的 Node.js 查询服务。当前 `QueryService.query(text)` 会校验单个非空字符串、去除首尾空白，并委托给搜索适配器。HTTP 层负责请求解析和服务错误的 HTTP 映射。

现有单查询入口已有调用方，必须保持兼容。`docs/current-system.md` 仅记录当前行为：尚未定义批量请求大小、逐项失败语义或并发策略。

## 原始用户请求

查询服务需要增加公开的批量查询 API，HTTP 调用方会在一次请求中提交多条查询。请先把输入校验、单项失败语义和 service/transport 的职责谈清楚；在我批准设计前不要改实现。

## 项目约束

- 只能使用 Node.js 内置能力。
- 当前 `node --test` 覆盖单查询行为。
- 公开 API 和模块职责的变更需要经过审阅的设计后才能实施。
