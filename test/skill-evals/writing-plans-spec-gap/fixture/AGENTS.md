# Webhook Signing Service Rules

- Treat the Spec as the behavior source only where it contains an accepted decision; an `accepted` label does not fill explicit open decisions.
- Public request headers, HTTP failures, security policy, and compatibility duration must be decided in the Spec before planning.
- When those decisions are missing, report their concrete impact and stop with a clean Git tree.
- Do not create placeholder documents or choose a security default for the user.
- Run `node --test` and generate Indexes only through the absolute hello-scholar CLI.
