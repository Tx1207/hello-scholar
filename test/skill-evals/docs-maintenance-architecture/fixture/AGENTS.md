# Project Rules

- This repository implements a retrieval service used by the paper-search API.
- Current Architecture describes implemented reality, not accepted or Draft intentions.
- Architecture changes require a source-backed semantic diff Proposal and explicit approval of the current file hash before writing.
- `hello-scholar/specs/`, `runs/`, code, tests, and result files are evidence, not Architecture-edit targets.
- Run `python3 -m unittest discover -s tests` and absolute `hello-scholar docs check` after an approved Architecture update.
