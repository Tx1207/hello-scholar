# Access Policy Service Rules

- `SPEC-028`, its current Plan, and its Tasks define the product contract; source, tests, callers, and persisted configuration must remain aligned with that contract.
- Changes to Bundle documents or their lifecycle state require explicit user authorization and the applicable review step.
- Do not change implementation, tests, callers, configuration, or Run material unless the user authorizes that work.
- Generate Indexes only with the absolute hello-scholar CLI. Run `npm test` and `docs check` from the project root.
