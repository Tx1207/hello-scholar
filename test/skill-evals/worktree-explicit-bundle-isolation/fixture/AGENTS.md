# Localization Parser Project Rules

- Inspect Git topology and user-owned working-tree state before creating isolation.
- Preserve the public tuple return type and dependency-free implementation.
- Treat the Accepted Spec, Approved Plan, and approved Current Tasks as implementation contracts, but do not implement them while preparing a Worktree.
- Never copy, stage, commit, overwrite, or remove the user's release-copy draft.
- Run the complete `unittest` suite in a newly created Worktree before reporting it ready.
