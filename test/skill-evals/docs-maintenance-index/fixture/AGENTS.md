# Project Rules

- This Node.js package renders stable summaries for experiment dashboards.
- Core documents and runtime code are fact sources; generated Indexes are derived navigation only.
- Never hand-edit a file carrying the hello-scholar generated marker.
- A request to sync navigation authorizes only the three canonical Index files.
- Run `node --test` before and after documentation maintenance.
- Run the absolute hello-scholar `docs sync` twice to prove idempotence.
