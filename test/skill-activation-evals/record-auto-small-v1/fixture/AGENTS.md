# Project Rules

- This repository contains a local policy parser and a fixed fixture input.
- `node scripts/check-policy.mjs` reads `fixtures/policy.json` and prints its result to stdout; it creates no output files.
- Do not modify source, tests, fixture inputs, package metadata, or project documentation.
- Use `npm test` to verify parser behavior.
- Do not create a Worktree from inside this repository.
